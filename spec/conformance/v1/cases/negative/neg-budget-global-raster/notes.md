# v1/cases/negative/neg-budget-global-raster

- 形态:`negative` 负例(PXL.md §13.3);`defect: budget`
- **受测侧**:阶段 R4(§11.2 第 14 行:会话预算,全局光栅项)
- 受测输入:`entry.pxl` + `parts/a01.pxl` … `parts/a04.pxl`
- 期望错误码:`PXL011`(见 `expected.error`,一行 + LF)
- 缺陷数量:**1**(全局光栅超 2^24)

## 构造:五个文档,每个都合法,加起来越界

每个文档的画布都是 `2048 × 2048`:
面积 = 4,194,304 = 2^22,**恰好等于** v0 §5.0.2 的面积上限(不超);
每个文档只有一个 op,且该 op 裁剪后的写入面积恰好是整张画布 → **自有光栅工作 = 4,194,304 = 2^22**,
恰好等于单文档光栅上限(不超,所以**不**报 `PXL002`)。

```text
entry.pxl        stamp parts/a01.pxl   -> 4,194,304
parts/a01.pxl    stamp a02.pxl         -> 4,194,304
parts/a02.pxl    stamp a03.pxl         -> 4,194,304
parts/a03.pxl    stamp a04.pxl         -> 4,194,304
parts/a04.pxl    fill                  -> 4,194,304
                                  总计 = 20,971,520
```

§10.2 的全局光栅上限是 **2^24 = 16,777,216**,于是 `20,971,520 > 16,777,216` → `PXL011`。

**为什么必须是 5 个而不是 4 个**:4 × 4,194,304 = 16,777,216,**恰好等于**上限而不超过。
本用例只靠“严格越界”成立,不依赖“等于算不算越界”的口径(该口径的歧义见
`neg-budget-ref-depth` 的待确认项 1)。

## 覆盖条款

- §10.2 全局预算表(全局光栅 2^24);
- §10.3 全局光栅计数口径:每个**唯一**渲染节点的内部 op 工作计一次;父文档中的 asset stamp
  按**实际裁剪后**的写入面积计一次;
- §12.3(PRD)同一口径:缓存命中不减免语义预算 —— 本用例每个节点只出现一次,不靠去重论证;
- §11.2 阶段 R4;v0 §5.0.2 的面积与单文档光栅上限(用来证明每条 op 本身合规)。

## 除全局光栅外一切都未越界(单缺陷的证明)

| 预算项 | 上限 | 实际 | 结论 |
|---|---:|---:|---|
| 单文档面积 | 2^22 | 2^22(恰好) | 不越界 |
| 单文档光栅工作 | 2^22 | 2^22(恰好) | 不越界(否则 `PXL002`) |
| 引用深度 | 64 | 4 | 远低 |
| 唯一渲染节点数 | 4,096 | 5 | 远低 |
| 唯一实际源文件数 | 8,192 | 5 | 远低 |
| 累计 PXL 字节 | 64 MiB | 约 1 KiB | 远低 |
| 累计 PNG 像素 | 2^24 | 0 | 0 |
| **全局光栅工作** | **2^24** | **20,971,520** | **越界** |

这条用例是“**每个文档独立合法、组合起来非法**”的最小构造:任何只做单文档校验、不做会话级
预算的实现都会把它渲染出来(而且真的会写 2000 万像素),本用例因此失败。

## 判定方式

实现必须以 `PXL011` 失败,且不产出任何输出文件。**不得**为了跑这条用例先去光栅化
2000 万像素:预算必须在光栅化**之前**判定(§11.2 第 14 行在第 15 行“光栅化与 PNG 编码”之前)。

## 与 v0 的差异

v0 只有单文档预算(全部 `PXL002`);v1 新增会话级预算与 `PXL011`。本条钉的是后者。
