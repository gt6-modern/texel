# syn-1x1-opaque

- 尺寸:1x1
- PNG:色彩类型 6(RGBA)、8 bit、非交错、行过滤器恒 0、无 PLTE/tRNS/额外 chunk
- 非透明色数(n):1

## 覆盖条款

`§4.5`(n = 1)、`§4.2`(char 档首字符 `0` 即 slot 1)、`§5.1`(`fill`)、`§5.0.1`(最小画布)。

## 期望值来源

唯一像素 `FF0000FF`:非全零且 A = 255 → 非透明,拿到 slot 1;palette = ["FF0000"],n = 1 → char;单条 `fill slot=1`。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 4 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
