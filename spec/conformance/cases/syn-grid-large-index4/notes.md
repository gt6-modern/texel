# syn-grid-large-index4

- 尺寸:512x512
- PNG:色彩类型 3(索引)+ PLTE 256 项(768 字节)、8 bit、非交错、行过滤器恒 0、无 tRNS
- 非透明色数(n):256

## 覆盖条款

`§5.0.2`(大尺寸 + 4 位 token 的组合必须仍产出合法 PXL)、`§4.5`(n = 256 → index4)、附录 A 第 6 步(全 GRID → 一条 `grid`)、`§8.5`(索引不得越过 PLTE 项数)。

## 期望值来源

样本索引 = `(37x + 91y) mod 256`。37 与 256 互素,故固定 y 时 x 取 0..511 会让 `37x mod 256` 取遍全部 256 个值;相邻两列差 37 ≢ 0 → 每行段长恒 1 → 全部 GRID 行、只有 1 个块 → 单条 `grid`(x = 0, y = 0, 512 行,每行 512 个 4 位 token)。PLTE 第 k 项是 `(k, 255-k, 7k mod 256)`:r 随 k 严格不同 → 256 个颜色两两不同 → n = 256。面积 512 × 512 = 262144 ≤ 2^22。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1048576 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
