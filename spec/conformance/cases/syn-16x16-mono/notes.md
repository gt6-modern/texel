# syn-16x16-mono

- 尺寸:16x16
- PNG:色彩类型 2(RGB)、8 bit、非交错、行过滤器恒 0、每行 48 字节、无 tRNS
- 非透明色数(n):1

## 覆盖条款

`§8.2` 第 3 行(色彩类型 2 → a = 255)、`§4.5`(n = 1)、`§5.1`/附录 A 第 2 步(整图纯色 → 单条 `fill`)、AGENTS.md §3.3(必须压缩)。

## 期望值来源

256 个像素全是 `336699` + a = 255;n = 1 → char 档;全图同 slot → `fill slot=1`,不得输出 256 条 `rect` 或一条 `grid`。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
