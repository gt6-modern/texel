# syn-png-rgb-trns

- 尺寸:16x16
- PNG:色彩类型 2(RGB)+ tRNS 6 字节 `0000 00FF 0000`、8 bit、非交错、行过滤器恒 0
- 非透明色数(n):3

## 覆盖条款

`§8.5`(色彩类型 2 的 tRNS 必须恰 6 字节;命中三元组 → alpha = 0 且 RGB 原样)、`§8.2` 第 4 行、`§7` 与 `§3.5`(命中像素是非透明的"不可见色")、`§4.5`(n = 3)。

## 期望值来源

三色竖带:列 0–5 是 `112233`,列 6–10 是 `00FF00`(与 tRNS 三元组相同 → a = 0),列 11–15 是 `445566`。展开后 3 个 texel 两两不同 → n = 3,其中 `(0,255,0,0)` 正是§7 关心的"RGB 非零而 A = 0"。每行三段、段长 6/5/5(全 ≥ 3)→ RUNNER 行,整图 1 个 RUNNER 块 → 3 条 `rect`(h = 16)。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
