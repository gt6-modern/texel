# op-mirror-from-oob-transparent

钉住 §5.6：`mirror` 的**读侧越界**必须往目标写**透明**（`00000000`），不是"什么都不写"。

为什么这条用例存在（GATE-4）：语料 `op-mirror-overlap` 的 notes 曾宣称钉住该行为，但它的
target 区本来就透明——写 0 与跳过产生同一份像素，两侧都绿。于是 Python 的 mirror 把"写透明"
改成"跳过"（MIRROR-1）后，全部语料仍然通过。

构造：画布 4x2 先整幅 `fill` 成不透明红，再 `mirror` from {x:0,y:-1,w:4,h:2} 到 (0,0)。
源第一行（y=-1）越界 → 目标第 0 行必须是透明；如果实现"跳过"，那一行会保留红色。
两种语义的像素摘要不同，因此这条用例可区分。
