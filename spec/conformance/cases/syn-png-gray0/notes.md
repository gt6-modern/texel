# syn-png-gray0

- 尺寸:16x16
- PNG:色彩类型 0(灰度)、8 bit、非交错、行过滤器恒 0、无 PLTE/tRNS/额外 chunk
- 非透明色数(n):4

## 覆盖条款

`§8.1`(色彩类型 0 属于接受集)、`§8.2` 第 1 行(无 tRNS:r = g = b = 样本、a = 255)、`§4.5`(n = 4)、`§7`(灰度 0 但 a = 255 不算透明)。

## 期望值来源

第 y 行整行取 `stops[y // 4]`,stops = (0x00, 0x55, 0xAA, 0xFF),即 4 条 4 行高的横带。展开后 n = 4:第一行的 `(0,0,0,255)` 不是四通道全零,仍占自己的非透明 slot。每行段长 16 → RUNNER 行,slot 逐带不同 → 4 条 `rect`(w = 16, h = 4)。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
