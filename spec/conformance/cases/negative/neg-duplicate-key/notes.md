## 缺陷(只有这一处)

顶层对象里出现了两个 `"width"`(1 与 2)。不同 JSON 解析器对重复键有的取首值、有的取末值、有的直接报错;§3.2 因此把「成员名重复」定为 `PXL001`,阶段 3 就拒绝,不进入后续任何检查。

本目录**没有** `input.png`,`expected.pixels.sha256` 也不存在——负例不产出期望像素,只钉错误码与「不留输出文件」。**没有** `expected.pxl`:负例绝不放它。
