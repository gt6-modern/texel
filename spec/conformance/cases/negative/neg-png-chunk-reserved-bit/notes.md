# negative/neg-png-chunk-reserved-bit

- 形态:**负例**(§13.1)
- **受测侧**:抽取侧(目录内只有 `input.png`,抽取器根本不读 PXL)
- 受测输入:`input.png`
- 期望错误码:`PXL006`(见 `expected.error`,一行 + LF)
- 缺陷数量:1(§13.1 / README §2.2 要求一个目录只放一个缺陷)

## 覆盖条款

`§8.5`(chunk 类型名第三个字节的保留位必须为 0,即必须是大写字母)。

## 缺陷(只有这一处)

IHDR 之后插入类型名 `tExt`:四个字节全是 ASCII 字母,但**第三字节 `x` 小写**→ 保留位为 1。必须拒绝。注意与 `neg-png-chunk-type-invalid`(类型名含数字)区分:那条只测「非字母」,测不到保留位。

`input.png` 实测 **108 字节**;本目录没有 `input.pxl`,也没有任何期望像素文件。

## 判据

§13.2c:实现必须以 `PXL006` 失败,且**不产出任何输出文件**(不得留半份)。
