## 覆盖条款

`§3.4`(行数组至少 1 行;空数组即 `PXL001`,不得当成 no-op)、`§11.1` 阶段 3。

## 缺陷(只有这一处)

`grid` op 的 `grid` 字段是 `[]`。§3.4 明确:没有「0 行矩形」这种东西,空数组必须在阶段 3 被拒绝,而不是当成空操作。

本目录**没有** `input.png`,`expected.pixels.sha256` 也不存在——负例不产出期望像素,只钉错误码与「不留输出文件」。**没有** `expected.pxl`:负例绝不放它。
