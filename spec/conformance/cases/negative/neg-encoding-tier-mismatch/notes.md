# negative/neg-encoding-tier-mismatch

- 形态:**负例**(§13.1)
- **受测侧**:渲染侧(目录内只有 `input.pxl`)
- 受测输入:`input.pxl`
- 期望错误码:`PXL003`(见 `expected.error`,一行 + LF)
- 缺陷数量:1(§13.1 / README §2.2 要求一个目录只放一个缺陷)

## 覆盖条款

`§4.5`(档位由 `palette` 长度唯一派生;声明值必须等于派生值)、`§11.1` 阶段 7。

## 缺陷(只有这一处)

`palette` 有 100 项(派生档 = `index`),却声明 `"encoding": "char"`。阶段 7 比对声明值与派生值,不符即 `PXL003`。注意本轮 `palette` 长度 100 **没有**超过声明档的上限(61)?它超过了——但那条不单列规则,因为派生档必然高于声明档,阶段 7 的比对会先命中,报的仍是 `PXL003`。

本目录**没有** `input.png`,`expected.pixels.sha256` 也不存在——负例不产出期望像素,只钉错误码与「不留输出文件」。**没有** `expected.pxl`:负例绝不放它。

## 判据

§13.2c:实现必须以 `PXL003` 失败,且**不产出任何输出文件**(不得留半份)。
