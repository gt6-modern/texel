- 形态:**负例**(§13.1)
- **受测侧**:渲染侧(目录内只有 `input.pxl`)

- 期望错误码:`PXL001`(见 `expected.error`,一行 + LF)

## 覆盖条款

`§3.2`(成员名重复)、`§11.1` 阶段 3 与「通用对象检查对任何对象都执行」。

## 缺陷(只有这一处)

**刻意的阶段序用例**:`{"op": "circle", "x": 1, "x": 2}` —— 未知 op 且同一对象内 `x` 重复。按 §11.1,成员名重复是**通用对象检查**,阶段 3 就报 `PXL001`;未知 op 只跳过 op 专属检查,不影响这一条。(这一份 `input.pxl` 因此不是规范形式——它必须保留重复键才能测到该规则。)

本目录**没有** `input.png`,`expected.pixels.sha256` 也不存在——负例不产出期望像素,只钉错误码与「不留输出文件」。**没有** `expected.pxl`:负例绝不放它。

§13.2c:实现必须以 `PXL001` 失败,且**不产出任何输出文件**(不得留半份)。
