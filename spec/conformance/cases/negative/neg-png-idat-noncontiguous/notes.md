# negative/neg-png-idat-noncontiguous

- 形态:**负例**(§13.1)
- **受测侧**:抽取侧(目录内只有 `input.png`,抽取器根本不读 PXL)
- 受测输入:`input.png`
- 期望错误码:`PXL006`(见 `expected.error`,一行 + LF)
- 缺陷数量:1(§13.1 / README §2.2 要求一个目录只放一个缺陷)

## 覆盖条款

`§8.5`(`IDAT` 必须连续出现,中间不得夹其它 chunk)。

## 缺陷(只有这一处)

两块 IDAT 之间夹了一条 `tEXt`。§8.5 要求 IDAT 连续出现、按顺序拼接;夹了别的 chunk 之后「先收全文件再解码」与「流式解码」会得到不同结果。

`input.png` 实测 **140 字节**;本目录没有 `input.pxl`,也没有任何期望像素文件。

## 判据

§13.2c:实现必须以 `PXL006` 失败,且**不产出任何输出文件**(不得留半份)。
