# negative/neg-priority-005-over-003-palette-capacity

- 形态:**负例**(§13.1)
- **受测侧**:渲染侧(目录内只有 `input.pxl`)
- 受测输入:`input.pxl`
- 期望错误码:`PXL005`(见 `expected.error`,一行 + LF)
- 缺陷数量:1(§13.1 / README §2.2 要求一个目录只放一个缺陷)

## 覆盖条款

`§4.5`(阶段 7 的前置条件:仅当 `n <= 65535` 才比对档位)、`§11.1` 阶段 9。

## 缺陷(只有这一处)

**刻意的阶段序用例**:`palette` 长度 65536 且 `encoding` 声明为 `char`。若阶段 7 照常执行会因档位不符报 `PXL003`;但 `n >= 65536` 时阶段 7 **被跳过**,必须由阶段 9 报 `PXL005`。

本目录**没有** `input.png`,`expected.pixels.sha256` 也不存在——负例不产出期望像素,只钉错误码与「不留输出文件」。**没有** `expected.pxl`:负例绝不放它。

§13.2c:实现必须以 `PXL005` 失败,且**不产出任何输出文件**(不得留半份)。
