# negative/neg-bitdepth16

- 形态:**负例**(§13.1)
- **受测侧**:抽取侧(目录内只有 `input.png`,抽取器根本不读 PXL)
- 受测输入:`input.png`
- 期望错误码:`PXL006`(见 `expected.error`,一行 + LF)
- 缺陷数量:1(§13.1 / README §2.2 要求一个目录只放一个缺陷)

## 覆盖条款

`§8.1`(样本深度仅接受 8)、`§8.3`(16 bit 必须显式拒绝,不得静默降位深)、`§3.6`。

## 缺陷(只有这一处)

IHDR 的样本深度写成 16(色彩类型 6,每像素 8 字节)。v0 的接受集只含 8 bit;任何降位深都是有损的,违反 §1 的无损前提,因此必须在**输入侧**拒绝。

`input.png` 实测 **80 字节**;本目录没有 `input.pxl`,也没有任何期望像素文件。

## 判据

§13.2c:实现必须以 `PXL006` 失败,且**不产出任何输出文件**(不得留半份)。
