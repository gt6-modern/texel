# negative/neg-png-area-over-limit

- 形态:**负例**(§13.1)
- **受测侧**:抽取侧(目录内只有 `input.png`,抽取器根本不读 PXL)
- 受测输入:`input.png`
- 期望错误码:`PXL006`(见 `expected.error`,一行 + LF)
- 缺陷数量:1(§13.1 / README §2.2 要求一个目录只放一个缺陷)

## 覆盖条款

`§8.3`(`width × height` 超过 §5.0.2 的面积上界即拒)、`§5.0.2`(`<= 2^22`)。

## 缺陷(只有这一处)

IHDR 声明 `2049 × 2048 = 4,196,352 > 2^22 = 4,194,304`。宽高各自都在 1..65536 内,只有乘积越界 —— 这条与文档侧的 `neg-size-area-over-limit` 成对,但报的是输入侧的 `PXL006`。

`input.png` 实测 **67 字节**;本目录没有 `input.pxl`,也没有任何期望像素文件。

## 判据

§13.2c:实现必须以 `PXL006` 失败,且**不产出任何输出文件**(不得留半份)。
