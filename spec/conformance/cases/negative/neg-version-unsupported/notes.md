# negative/neg-version-unsupported

- 形态:**负例**(§13.1)
- **受测侧**:渲染侧(目录内只有 `input.pxl`)
- 受测输入:`input.pxl`
- 期望错误码:`PXL007`(见 `expected.error`,一行 + LF)
- 缺陷数量:1(§13.1 / README §2.2 要求一个目录只放一个缺陷)

## 覆盖条款

`§12`(域内但不等于 1 的整数 `version` 报 `PXL007`)、Version dispatch 第 3 条、`§3.8`(只看词法值,不做隐式迁移)、Extension §11.1。

## 缺陷(只有这一处)

`version` 写成 `2`:词法是整数、落在分派域 `0..65535` 之内,只是本 compiler 不支持该版本。正确结果是 `PXL007`,**不是** `PXL001`(那不是语法错),**不是** `PXL002`(那不是数值域),更不允许实现「猜一个相近版本继续渲染」——这条钉住版本分派先于一切字段校验。

本目录**没有** `input.png`,`expected.pixels.sha256` 也不存在——负例不产出期望像素,只钉错误码与「不留输出文件」。**没有** `expected.pxl`:负例绝不放它。

## 判据

§13.2c:实现必须以 `PXL007` 失败,且**不产出任何输出文件**(不得留半份)。
