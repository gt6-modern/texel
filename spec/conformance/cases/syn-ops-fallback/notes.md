# syn-ops-fallback

- 尺寸:65535x4
- PNG:色彩类型 0(灰度)、8 bit、非交错、行过滤器恒 0、无 tRNS;每行解压后 65536 字节(1 过滤器字节 + 65535 样本)
- 非透明色数(n):2

## 覆盖条款

`§5.0.2`(接受的 PNG 一定能抽成合法 PXL:每层 ops ≤ `OPS_CAP`)、附录 A 第 8 步(ops 超预算 → 整层退化为一条覆盖全图的 `grid`)、`§8.1`(宽度 65535 ≤ 65536、面积 ≤ 2^22 故合法)。

## 期望值来源

65535 = 3 × 21845,故每行恰好 21845 段、段长恒为 3(≥ MIN_RUN = 3)→ 每行都是 RUNNER 行。相邻行反色:第 0 行以 `00` 起、第 1 行以 `FF` 起,同一列的相邻两行 slot 不同 → 不能垂直合并。于是常规输出是 21845 × 4 = 87380 条 `rect`,超过 `OPS_CAP = 32768`,整层按附录 A 第 8 步回退为一条覆盖全图的 `grid`。灰度 0x00 → `(0,0,0,255)`、0xFF → `(255,255,255,255)` → n = 2。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1048560 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。

合法性:宽 65535 ≤ 65536,面积 65535 × 4 = 262140 ≤ 2^22(§5.0.2),所以这是**合法输入**,不能靠拒绝来绕开 ops 上界。
