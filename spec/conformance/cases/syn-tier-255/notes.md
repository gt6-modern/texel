# syn-tier-255

- 尺寸:255x1
- PNG:色彩类型 6(RGBA)、8 bit、非交错、行过滤器恒 0、单行 1020 字节
- 非透明色数(n):255

## 覆盖条款

`§4.5`(255 色仍在 index 档)、`§4.1`(index 档容量 256 − 1 = 255)、`§4.3`(`00` 保留给透明,最后一个是 `FF`)。

## 期望值来源

255 个像素 255 个互不相同的颜色;n = 255 = 256 − 1 → 仍是 index:透明 `00` 加 255 个非透明 slot 恰好用满两位十六进制的 256 个值。整行段长恒 1 → 一条 `grid`。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1020 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
