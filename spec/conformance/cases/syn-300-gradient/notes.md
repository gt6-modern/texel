# syn-300-gradient

- 尺寸:20x15
- PNG:色彩类型 6(RGBA)、8 bit、非交错、行过滤器恒 0、每行 80 字节
- 非透明色数(n):300

## 覆盖条款

`§4.5`(n = 300 → 跳过 index 直接 index4)、`§4.3`(index4 token 宽 4、大写零填充、`0000` 保留给透明)、`§4.4`(行优先首次出现顺序即扫描顺序)、附录 A 第 6 步(全 GRID → 一条 `grid`)。

## 期望值来源

像素 (x, y) 的颜色是 `(12x, 17y, 5(x+y))`,a = 255:x 取 0..19 使 r 互不相同,y 取 0..14 使 g 互不相同,于是 20 × 15 = 300 个像素两两不同 → n = 300。相邻列必不同 → 每行段长恒 1 → 全部 GRID 行且只有 1 个块 → 单条 `grid`(x = 0, y = 0, 15 行)。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1200 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
