# syn-tier-256

- 尺寸:256x1
- PNG:色彩类型 6(RGBA)、8 bit、非交错、行过滤器恒 0、单行 1024 字节
- 非透明色数(n):256

## 覆盖条款

`§4.5`(256 色必须升到 index4)、`§4.1`(index 档放不下 256 个非透明色)、`§4.3`(四位大写十六进制、`0000` 保留给透明)。

## 期望值来源

256 个像素 256 个互不相同的颜色;n = 256 > 255 → 必须升到 index4:index 档 256 个值里 `00` 已被透明占用。整行段长恒 1 → 一条 `grid`,token 为 `0001`..`0100`。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
