# syn-png-palette-trns

- 尺寸:16x16
- PNG:色彩类型 3(索引)+ PLTE 8 项 + tRNS 3 字节 `0080FF`、8 bit、非交错、行过滤器恒 0
- 非透明色数(n):5

## 覆盖条款

`§8.2` 第 5 行(tRNS 的**两条**分支:范围内取该项 alpha、`i >= tRNS 长度` 时 255)、`§8.5`(tRNS 长度不得超过 PLTE 项数)、`§3.5` 与 `§7`(RGB 非零而 A = 0 仍占 slot)、`§4.5`(n = 5 → char)。

## 期望值来源

PLTE 保留 8 项,tRNS 只给 3 项(`00` / `80` / `FF`),像素只使用索引 0..4:第 x 列的索引是 `(x // 2) % 5`,每段 2 列、段长恒 2。两条 tRNS 分支各由不同的索引覆盖:索引 0 / 1 / 2 落在 tRNS 长度内 → alpha 取该项,依次是 0 / 128 / 255(索引 0 得到 `(255,0,0,0)`:RGB 非零而 A = 0,按 §3.5 保留自己的 slot,不是透明 slot);索引 3 / 4 的 `i = 3, 4 >= tRNS 长度 3` → alpha 按 255。5 个 texel 两两不同 → n = 5。每行段长 2 → 全部 GRID 行 → 单条 `grid`。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
