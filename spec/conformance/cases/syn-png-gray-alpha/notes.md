# syn-png-gray-alpha

- 尺寸:16x16
- PNG:色彩类型 4(灰度 + alpha)、8 bit、非交错、行过滤器恒 0、无 PLTE/tRNS
- 非透明色数(n):6

## 覆盖条款

`§8.1`(色彩类型 4:不得有 PLTE 或 tRNS)、`§8.2` 第 7 行(r = g = b = 样本 0、a = 样本 1)、`§3.5`(A = 0 但灰度非零 → 仍是非透明 slot)、`§4.5`(n = 6)。

## 期望值来源

第 y 行整行取 `_GRAY_ALPHA_PAIRS[y % 6]`,组合为 (0x20,0x00) (0x40,0x40) (0x60,0x80) (0x80,0xC0) (0xA0,0xFF) (0xFF,0x7F)。展开成 `(g,g,g,a)` 后 6 个 texel 两两不同 → n = 6;第一行 `(32,32,32,0)` 的 A = 0 但灰度非零,按 §3.5 不并入透明 slot。每行段长 16 → 16 条 `rect`(相邻行 slot 不同,不能垂直合并)。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
