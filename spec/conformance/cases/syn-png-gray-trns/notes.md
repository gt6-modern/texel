# syn-png-gray-trns

- 尺寸:16x16
- PNG:色彩类型 0(灰度)+ tRNS 2 字节 `0080`、8 bit、非交错、行过滤器恒 0
- 非透明色数(n):2

## 覆盖条款

`§8.5`(色彩类型 0 的 tRNS 必须恰 2 字节,值按大端与样本比较)、`§8.2` 第 2 行(命中 → a = 0,RGB 原样)、`§7` 与 `§3.5`(RGB 非零而 A = 0 的像素保留自己的 slot,不得并入透明 slot)。

## 期望值来源

tRNS 按大端读出 = 0x0080 = 128。列 0–7 的样本是 128,命中 → `(128,128,128,0)`;列 8–15 的样本是 0,未命中 → `(0,0,0,255)`。n = 2:`(128,128,128,0)` 不是四通道全零,按 §3.5 占自己的 slot。每行两段、段长 8 → 2 条 `rect`(h = 16)。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
