# syn-64x32-nonsquare

- 尺寸:64x32
- PNG:色彩类型 6(RGBA)、8 bit、非交错、行过滤器恒 0、每行 256 字节
- 非透明色数(n):8

## 覆盖条款

`§4.5`(n = 8 → char)、`§5.2`(`rect` 的右开区间与 `h`)、附录 A 第 5 步(同块内 `(x, w, slot)` 相同 → `h` 加 1)、`§5.0.2`(面积 2048)。

## 期望值来源

8 条 8 px 竖带贯穿全高:每行 8 段、段长恒 8(≥ 3)→ 32 行全是 RUNNER 行、整图 1 个 RUNNER 块。同一带在每一行的 `(x, w, slot)` 完全相同 → 垂直合并成 8 条 `rect`(w = 8, h = 32)。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 8192 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
