# syn-16x512-strip

- 尺寸:16x512
- PNG:色彩类型 6(RGBA)、8 bit、非交错、行过滤器恒 0、每行 64 字节
- 非透明色数(n):6

## 覆盖条款

`§4.5`(n = 6 → char)、`§5.0.2`(面积 16 × 512 = 8192 ≤ 2^22)、附录 A 第 4–6 步(纵向多块切分;`grid` 的 `y` 取块首行)、`§3.4`(`grid` 每行 token 数恒等于宽)。

## 期望值来源

每 16 行是一帧,帧内按 `(y % 16 + 帧号) % 6` 轮转 6 种行型:行型 0/2/4 的段长全 ≥ 3(RUNNER),行型 1/3/5 含段长 1 或 2(GRID)。帧号参与轮转,好让相邻帧不总以同一行型开始,从而在同一竖列上既产生可垂直合并的 `rect`,也产生多段 GRID 块。6 个颜色全部出现 → n = 6。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 32768 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
