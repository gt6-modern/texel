# syn-png-palette

- 尺寸:16x16
- PNG:色彩类型 3(索引)+ PLTE 8 项(24 字节)、8 bit、非交错、行过滤器恒 0、无 tRNS
- 非透明色数(n):8

## 覆盖条款

`§8.1`(色彩类型 3 必须有 PLTE)、`§8.2` 第 6 行(索引查 PLTE、a = 255)、`§4.5`(n = 8 → char)、`§8.5`(PLTE 长度必须是 3 的倍数、项数 1..256)。

## 期望值来源

第 x 列的样本索引是 `x // 2`,8 个索引 0..7 各占 2 列、全部被用到;每像素展开为 `(PLTE[3i], PLTE[3i+1], PLTE[3i+2], 255)`。8 个颜色两两不同 → n = 8。每行段长恒 2(< MIN_RUN = 3)→ 全部 GRID 行 → 单条 `grid`。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
