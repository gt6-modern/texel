# syn-png-gray-trns-highbyte

- 尺寸:16x16
- PNG:色彩类型 0(灰度)+ tRNS 2 字节 `0180`(高字节非 0)、8 bit、非交错、行过滤器恒 0
- 非透明色数(n):2

## 覆盖条款

`§8.5`(色彩类型 0 的 tRNS 必须**先按样本深度掩掉高位**再比较 —— PNG 第三版 §11.3.2.1)、`§8.2` 第 2 行(命中 → a = 0,RGB 原样)、`§7` 与 `§3.5`。

## 期望值来源

tRNS = 0x0180,位深 8 → 有效比较值 `0x0180 & 0xFF = 0x80`。列 0–7 的样本是 128,**命中** → `(128,128,128,0)`;列 8–15 的样本是 0,未命中 → `(0,0,0,255)`。早前规范按 16 位整值比较(0x0180 ≠ 0x80,不命中),与 PNG 标准冲突,已更正。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 1024 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
