# syn-tier-62

- 尺寸:62x1
- PNG:色彩类型 6(RGBA)、8 bit、非交错、行过滤器恒 0、单行 248 字节
- 非透明色数(n):62

## 覆盖条款

`§4.5`(62 色必须升到 index 档)、`§4.1`(char 档容量 62 − 1 = 61)、`§4.3`(两位大写十六进制)。

## 期望值来源

62 个像素 62 个互不相同的颜色;n = 62 > 61 → 必须升到 index:char 档 62 个值里有一个已被透明 token `.` 占用,物理上放不下第 62 个非透明色。整行段长恒 1 → 一条 `grid`,token 为 `01`..`3E`。


`expected.pixels.sha256` 按 §13.4 计算:逐行、行内自左向右、自上而下,每像素 R,G,B,A 四字节,无填充,共 248 字节;由本文件持有的**意图像素**直接算出,不经过任何 PNG 解码。
