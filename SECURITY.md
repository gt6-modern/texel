
# Security Policy

[简体中文](SECURITY.zh-CN.md)

Security fixes are provided for the latest released 0.x line. Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting at <https://github.com/gt6-modern/texel/security/advisories/new> and include affected versions, impact, reproduction steps, and any proposed mitigation. Maintainers will acknowledge a complete report within seven days and coordinate disclosure after a fix is available.
